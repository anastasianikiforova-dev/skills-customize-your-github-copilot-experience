
# 📘 Assignment: Games in Python

## 🎯 Objective

Create interactive games using Python to practice string manipulation, loops, conditionals, and user input handling. You'll develop games that engage players while reinforcing fundamental programming concepts.

## 📝 Tasks

### 🛠️ Build a Hangman Game

#### Description
Develop the classic word-guessing game where players attempt to guess a hidden word by suggesting letters before running out of attempts. This task will help you practice string manipulation, loops, conditionals, and random selection.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and display current progress in the format (_ _ _ _ _ _)
- Track and display remaining incorrect guesses
- End the game when the word is correctly guessed or attempts are exhausted
- Display appropriate win/lose messages with the correct word

### 🛠️ Enhance Your Game

#### Description
Extend your game with additional features to improve user experience and add replay functionality.

#### Requirements
Completed program should:

- Display a difficulty level option that affects the word list or number of attempts
- Implement a replay feature that allows players to play multiple rounds without restarting
- Provide clear feedback on invalid inputs (already guessed letters, non-letter characters)
- Track and display game statistics (wins, losses, total attempts)
